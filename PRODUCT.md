# Product

## Register

brand

## Users

- **Primary**: Design/dev community — Awwwards judges, front-end engineers, tech X / r/webdev browsers who judge portfolios on craft and share the exceptional ones. They arrive skeptical, have seen a thousand AI purple-gradient portfolios, and stay only if the first 10 seconds feel authored. Job: experience the site, appreciate execution, share it.
- **Secondary**: Recruiters, hiring managers, hackathon judges evaluating James Gabriel Elijah Ty (BS CS, UP Cebu, July 2027) for internships and competitions. Job: extract projects, stack, experience, awards, contact in under 60 seconds via hash deep-links.
- **Tertiary**: Cloud / AI community peers — GitHub Campus Experts, AWS builders, hackathon circles.

## Product Purpose

A single-page developer portfolio that IS the resume proof of skill: a serious professional site whose interface borrows the interaction craft of game UI — save-select boot, tactical HUD frame, skill-tree grid. Inspiration lives in layout, color, and motion only. All copy stays recruiter-serious. Success = visitors finish the experience, remember it, share it, while recruiters extract every fact fast.

## Brand Personality

Precise, confident, quietly stylish. A developer with taste, not a character. First-person, human, direct. Grand through craft and restraint, never through costume. If a line would not survive on a senior engineer portfolio, it does not ship. Three words: precise, assured, restrained.

## Anti-references

- Generic AI-portfolio aesthetics: purple gradients on white, Inter/Roboto, glassmorphic cards floating in a void
- Reusing the previous build wholesale: charcoal/red `#250505` + royal gold + Cinzel/EB Garamond + blade-cut wipe. That identity is retired; the new build must not read as a re-skin
- Roleplay copy in any form: no fantasy vocabulary (quest, trophy, summoning, HP, lore), no fictional framing, no press-start energy in words. Theme is geometry, color, motion, never text
- Sites where theme buries content: must carry full CV depth with real claims next to complete facts
- Overstuffed game HUDs (every-corner-blinking): restraint in chrome, generosity in craft

## Design Principles

1. **The experience is the portfolio**: choreography, transitions, menu craft demonstrate engineering skill; the site is project #1.
2. **Theme in design, not words**: game inspiration lives in layout, color, motion; every string reads like a serious professional site.
3. **Style serves function**: if visuals cost usability, usability wins; every flourish must survive the 60-second recruiter test.
4. **Experience is a hero track**: roles and community impact (ISCOLab, Campus Expert 1%, AWS 200+, UPCSG 75+) sit alongside systems work, not in a footer.
5. **Respect the visitor**: reduced motion, keyboard, touch, deep-links first-class. Performance is aesthetic: 60fps on a mid laptop or it is broken.

## Accessibility & Inclusion

- WCAG 2.1 AA: text contrast >= 4.5:1, visible focus, semantic headings, real DOM content (decorative canvas aria-hidden)
- `prefers-reduced-motion`: instant transitions, static ambience, no shake/flicker/typewriter
- Full keyboard: menu via arrows/Enter/Esc, visible focus, skip-link
- Touch: targets >= 44px, single-column under 720px
- Hash deep-links (`#/skills`, `#/experience`) for fast extraction; SEO/OG meta for previews
